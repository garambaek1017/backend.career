# 백엔드 개발자 백가람 · 포트폴리오

`index.html`을 브라우저에서 열면 바로 실행됩니다. 페이지를 보는 데 서버나 설치가 필요하지 않습니다. 다른 곳으로 옮길 때는 폴더 전체를 함께 옮기세요.

## 프로젝트 수정

페이지 왼쪽 위의 **고양이 발바닥** 버튼으로 프로젝트 편집기를 열고, 드롭다운에서 수정할 프로젝트를 고르세요. **+** 버튼으로 프로젝트를 추가할 수 있습니다. **미리보기 적용**은 현재 페이지에만 반영합니다. **JSON 저장**을 눌러 이 폴더의 파일에 저장하거나, 다운로드된 파일을 이 폴더의 projects.json으로 옮기세요. 그 뒤 아래 2~3단계를 실행하면 새로고침 후에도 반영됩니다.

텍스트 편집기에서 직접 수정할 수도 있습니다.

1. UTF-8로 `projects.json`을 열어 내용을 수정하고 저장합니다.
2. 이 폴더의 `update-portfolio.bat`을 더블클릭합니다. 이 단계에는 Node.js가 필요합니다.
3. 브라우저에서 `index.html`을 새로고침합니다.

`title`, `company`, `period`, `summary`는 카드에 바로 표시됩니다. `description`, `responsibilities`, `techStack`은 카드를 펼쳤을 때 표시됩니다. 배열의 항목 순서가 카드 순서이며, 항목을 추가하거나 삭제하면 프로젝트 개수도 함께 갱신됩니다.

## 회사별 경력과 총 경력 수정

`career.json`에서 회사명과 재직 기간을 수정한 뒤 `update-portfolio.bat`을 더블클릭하고 브라우저를 새로고침합니다. 첫 화면의 총 경력과 회사별 경력 목록이 함께 갱신됩니다.

시작과 종료는 `YYYY-MM` 형식입니다. 재직 중이면 `"end": null`로 두면 명령을 실행한 시점의 한국 시간 기준 현재 월까지 계산합니다. 시작 월과 종료 월을 포함하며, 여러 회사의 기간이 겹치는 달은 한 번만 계산합니다.

## 연락처 링크 수정

`links.json`의 `github`, `blog`, `youtube`에 공개할 HTTPS 주소를 입력하고 `update-portfolio.bat`을 더블클릭합니다. 주소를 입력한 항목만 클릭할 수 있고, `null`인 항목은 이름만 표시됩니다. GitHub에 배포할 때는 수정한 `links.json`과 갱신된 `index.html`을 함께 올립니다.

Tab으로 이동하고 Enter 또는 Space로 카드를 열거나 닫을 수 있습니다. 인포그래픽 확대는 닫기 버튼 또는 Esc로 닫을 수 있습니다.
